Unicode and fonts
TrueType text at any size, in every script the fonts cover.

Scalable text

The desktop used to draw text from small bitmaps baked at a fixed size. It now reads TrueType fonts from C:\WRLD\Fonts and rasterises each glyph as it is needed, so the same face can be any size and every character in the file can be shown. The font files are Liberation Sans and Liberation Mono (SIL Open Font License); the licence is in the same folder.

Document text is UTF-8 from the parser to the screen. There is no transliteration step any more: an accented letter, a Greek word or a Cyrillic name is stored as written and drawn as written.

The line height still comes from the old bitmap metrics, so the layout of existing windows does not move. Only the glyphs themselves are new.

What is not there yet

The fonts cover Latin, Greek, Cyrillic, punctuation, arrows and a little maths. Chinese, Japanese, Korean and emoji are not in Liberation, so they come out as an empty box. There is no hinting (the rasteriser ignores the font’s size hints), no shaping (Arabic and Indic joining) and no right-to-left layout; those need a shaper such as HarfBuzz. Syllabaries and historic scripts need a font that contains them.
