Welcome to THE WRLD OS!
=====================

THE WRLD OS is a from-scratch 32-bit x86 operating system with an XP-style
shell. Things to try:

  * Start > All Programs > Samples: run a real Win32 .exe, a shell script
    and mount an Apple .dmg disk image.
  * Control Panel > Appearance and Personalization > Personalization:
    switch between Luna (Blue), Olive Green, Silver and Classic, and drag
    the colour hue slider to recolour the whole interface.
  * Control Panel "View by" lets you switch between Category, Large icons
    and Small icons, like Windows 7.
  * Command Prompt: type "help". Try:  ls -l C:/Samples | grep exe
  * Task Manager (Ctrl+Shift+Esc) shows tasks, CPU and memory graphs.

Running from the CD (live session), everything lives in RAM, so changes are
lost when you restart. To keep your files and settings, double-click
"Install THE WRLD OS" on the desktop (or choose Install in the CD boot menu):
Setup partitions and formats a hard disk, copies the system and installs the
boot loader. After that, all changes are saved to the disk.
