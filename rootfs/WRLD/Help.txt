THE WRLD OS Help and Support
==========================

GETTING AROUND
  Start menu ........ click "start" or press the WRLD key (the key with the flag logo) / Ctrl+Esc
  Switch windows .... Alt+Tab, or click a taskbar button
  Close a window .... Alt+F4 or the red X button
  Task Manager ...... Ctrl+Shift+Esc or Ctrl+Alt+Del
  Desktop ........... right-click for New Folder / New Text Document / Properties

VISUAL STYLES
  Control Panel > Appearance and Personalization > Personalization
  - Luna (Blue), Olive Green, Silver, Royale (deeper XP blue), WRLD
    Classic, Aero (translucent blurred glass), Vista Aero (smoky glass,
    black taskbar), Plex (Longhorn-style glossy blue) and Metro (flat,
    square, Windows 8-style)
  - Colour hue slider (0-359 degrees), saturation and lightness sliders
    recolour any style
  - Desktop backgrounds: Meadow, Azure, Sunset, Aurora, Dunes or a solid colour
  Every style is a text file in C:\WRLD\Resources\Themes (*.wrldstyle).
  "Create a style..." in Personalization makes your own from the current one;
  double-click a .wrldstyle file to install and apply it.
  From the Command Prompt:  theme list   /   theme aero   /   theme olive 40
                            theme saturation -40   /   theme lightness 20

THE INTERNET
  The WRLD Browser (Start menu > Internet, or the globe on the Quick Launch
  bar) opens web pages over HTTP and HTTPS (TLS 1.3 or 1.2, through Mbed TLS).
  It has tabs (Ctrl+T new, Ctrl+W close, Ctrl+Tab switch, middle-click a
  link to open it in a new tab) and a bookmarks bar. It shows HTML, CSS
  (selectors, boxes with margins, padding, borders and widths, flexbox,
  grid, floats, positioning, CSS variables and linked style sheets), SVG icons, tables, forms and PNG/GIF/JPEG/BMP pictures, and runs JavaScript (QuickJS)
  with a DOM, events, timers, localStorage and fetch/XMLHttpRequest.
  Big web apps may still not work; text-heavy sites work best.
  Tools menu: Enable JavaScript, Script Messages (errors and console.log),
  Block Ads, Allow Ads on This Site, Edit Ad Blocker List.
  The ad blocker skips pictures/scripts from ~140 ad and tracking servers and
  hides ad slots. Your own rules go in C:\WRLD\adblock.txt.
  If a page uses more than 500 MB of memory, you are asked whether to let it
  continue or stop it.
  Command Prompt: js FILE.js, js -e "CODE" runs JavaScript.
  Command Prompt: ipconfig (/renew), ping HOST, nslookup NAME,
                  wget URL [-O FILE], curl URL, sha256sum FILE
  Extra trusted certificates (.crt/.pem) go in C:\WRLD\Certificates.
  Host name overrides go in C:\WRLD\hosts ("10.0.0.5  myserver").
  Supported network cards (wired only):
    Intel PRO/1000, e1000e, I217/I218/I219, I210/I211/I350 (igb)
    Realtek RTL8111/8168/8169/810x/8125 and RTL8139
    AMD PCnet (VMware "vlance", VirtualBox PCnet), VMware VMXNET3, VirtIO
  Type devices to see your card and its driver; ipconfig shows the address.

INSTALLING TO A HARD DISK
  Double-click "Install THE WRLD OS" on the live desktop, or pick "Install
  THE WRLD OS" in the CD boot menu. Setup (keyboard: arrows, ENTER, F8, F3)
  lets you create/delete partitions, formats NTFS or FAT32, copies the system and
  installs the GRUB boot loader, then restarts. The first boot from the disk
  asks for your name, computer name, time zone and visual style. Settings are
  saved in C:\WRLD\wrld.ini; files are written back to the disk within a
  couple of seconds and when you shut down. Works with IDE, SATA (AHCI),
  NVMe, SCSI (LSI Logic, LSI Logic SAS, VMware Paravirtual, virtio-scsi) and
  virtio disks.

MUSIC
  THE WRLD Media Player (Start menu) plays MP3 and WAV files: double-click
  one, or open the player and pick a song in the Library. Three sample
  tracks are in My Documents\My Music. Now Playing shows a visualisation;
  click the arrows under it to change it. Keys: Space play/pause, Ctrl+F
  next, Ctrl+B previous, Ctrl+S stop, F8 mute, F9/F10 volume.

3D
  Control Panel > Visual Effects > Enable 3D acceleration turns the WRLD 3D
  engine on or off. With it on, Alt+Tab shows your windows in Flip 3D: Tab
  or the mouse wheel moves through them, letting go of Alt picks one, Esc
  goes back (Ctrl+Alt+Tab keeps it open). Start > All Programs > WRLD 3D
  shows a 3D test scene. The engine runs on the processor.
  Windows programs can draw 3D through OpenGL 1.1 (opengl32.dll, glu32.dll),
  Direct3D 9 (d3d9.dll, fixed function) and Direct3D 10 (d3d10.dll, with
  vertex and pixel shaders run on the processor). Try C:\Samples\glcube.exe,
  d3dcube.exe and d3d10cube.exe. The shader cube defaults to SM4; --sm5 or --sm6
  selects WRLD's staged SM5.0 DXBC / SM6.0 DXIL vertex/pixel extensions, not
  D3D11/12 compatibility. --bench logs a fixed 120-frame CPU benchmark.
  C:\Samples\shaderprobe.exe checks uploads, rejections and profile queries.
  Direct3D 10 programs must ship compiled shaders: compiling HLSL while the
  program runs is not supported. Vulkan is not
  available: vulkan-1.dll reports no device, so programs that try it fall
  back to Direct3D or OpenGL. With 3D acceleration off, these programs are
  told 3D is unavailable.

SOUND AND DISPLAY
  Control Panel > Hardware and Sound > Sound: volume, mute, and the startup /
  shutdown sounds (C:\WRLD\Media). Supported sound cards: Intel High
  Definition Audio, AC'97 (Intel, nVidia, AMD, SiS, VIA), C-Media CMI8738,
  Ensoniq AudioPCI ES1370 and ES1371/ES1373, VirtIO sound, Sound Blaster 16
  and Windows Sound System (CS4231A). Command Prompt: volume 60, play FILE.wav
  No sound? "sndinfo" in the Command Prompt shows the card, the codec route
  and whether playback is advancing. In VMware, also check that the sound
  card is connected (VM > Settings > Sound Card > Connected).
  Control Panel > Appearance > Display: screen resolution (QEMU/Bochs VGA,
  VirtualBox VBoxVGA/VMSVGA, VMware SVGA). Command Prompt: display 1280x800

RUNNING PROGRAMS
  THE WRLD OS comes in two editions: the 32-bit one (wrldos.iso) runs 32-bit
  (x86) programs, the 64-bit one (wrldos64.iso, "Home Edition x64") runs
  64-bit (x64) programs; build those with x86_64-w64-mingw32-gcc.
  .exe  Win32 PE programs (console and GUI). Each process gets its own
        address space; kernel32, msvcrt, user32, gdi32, advapi32 and shell32
        are implemented natively. Build your own with:
            i686-w64-mingw32-gcc -O2 prog.c -o prog.exe            (console)
            i686-w64-mingw32-gcc -O2 -mwindows prog.c -o prog.exe -lgdi32 (GUI)
        64-bit (x64), .NET and 16-bit DOS programs are detected and refused.
  .sh   Shell scripts run on the built-in POSIX-style shell: variables,
        $(...), $((...)), pipes, redirection, if/while/until/for/case,
        functions, globbing and ~70 builtins (type "help").
  .dmg  Apple UDIF disk images (raw, zero-fill and zlib "UDZO" chunks) are
        decoded and their FAT volume is mounted as a new drive letter.
        Script-based .app bundles inside them can be launched; native
        Mach-O binaries are identified but cannot execute.

DEVICES AND DRIVERS
  Every driver is built in. Control Panel > Hardware and Sound > Device
  Manager lists each device, its driver and whether it is working; a
  question mark means THE WRLD OS has no driver for that device.
  A balloon says "Found New Hardware" when you add or plug in a device.

  devices (every device and its driver; -p shows only problems),
  driverquery (the built-in drivers), lsusb
  open FILE (default program), notepad FILE, explorer, control, taskmgr
