THE WRLD OS cursor sets
=======================

Put each set in its own folder here, for example:

    C:\WRLD\Cursors\Neon\arrow.cur
    C:\WRLD\Cursors\Neon\ibeam.cur
    C:\WRLD\Cursors\Neon\hand.cur

Then choose the set in Control Panel > Appearance and Personalization >
Advanced Appearance.  The setting is remembered for the user.

Cursor files are standard Windows .cur files (32-bit or 24-bit DIB, with a
hotspot).  The file names the system looks for are:

    arrow.cur       normal pointer
    ibeam.cur       text cursor
    hand.cur        link/hand cursor
    sizens.cur      vertical resize
    sizewe.cur      horizontal resize
    sizenwse.cur    diagonal resize
    sizenesw.cur    other diagonal resize
    busy.cur        busy/wait cursor
    move.cur        move cursor
    cross.cur       crosshair

A set may contain only the cursors it changes; any missing file keeps the
built-in cursor.
